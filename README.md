# DerbyMouth

Web game 1v1 real-time football pub banter battle — World Cup 2026.

## Bắt đầu với Claude Code (VS Code)

```bash
npm install
npm run dev        # mở http://localhost:5173 thấy chữ DERBYMOUTH = skeleton OK
```

Mở thư mục này trong VS Code, bật Claude Code, gõ:

> Đọc CLAUDE.md, docs/PLAN.md, docs/CARDS.md và docs/TASKS.md. Bắt đầu làm task 1.2.

Claude Code sẽ tự nắm toàn bộ context và build theo thứ tự task.

## Tài liệu
- `CLAUDE.md` — quy tắc + context cho Claude Code (file quan trọng nhất)
- `docs/PLAN.md` — full game design + kiến trúc + roadmap
- `docs/CARDS.md` — 20 card + công thức damage
- `docs/TASKS.md` — checklist theo phase, làm tuần tự
